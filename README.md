# SafeWhere Product Case Study

A responsive, single-page product-management case study built from the SafeWhere business plan and Capital Factory pitch materials.

## Preview locally

Run a small local server from this folder:

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000`.

## Deploy on Vercel

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository.
3. In Vercel, select **Add New > Project** and import the repository.
4. Leave **Framework Preset** as `Other` and click **Deploy**.
5. For future edits, replace the changed files in the same GitHub repository and commit them. Vercel will automatically update the same project and URL.
6. After deployment, connect a custom domain under **Project Settings > Domains** if desired.

No build command or environment variables are required.
